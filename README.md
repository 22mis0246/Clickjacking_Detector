## 📌 Description
This project demonstrates a clickjacking attack and provides a browser extension to detect it.

## ⚙️ Features
- Simulates clickjacking using iframe
- Detects hidden iframes
- Alerts users about potential risks

## 🛠 Technologies
- HTML, CSS, JavaScript
- Chrome Extension (Manifest v3)

## 🚀 How to Run
1. Open attacker.html using Live Server
2. Click "Start Game" to see attack
3. Load extension in Chrome
4. Warning appears automatically

## 🛡️ Security Concept
Detects hidden iframes used in clickjacking attacks
